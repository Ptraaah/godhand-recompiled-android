# v0.43-m42 — first playable public build

Release page: https://github.com/Ptraaah/godhand-recompiled-android/releases/tag/v0.43-m42
(pre-release, tag v0.43-m42). These are the release notes as published.

God Hand, recompiled to run natively on Android. Not an emulator: the
game's code is translated ahead of time into native ARM code, and the app
around it is built for phones from the start.

Watch the trailer: https://youtu.be/i7LGPYvCylo

You bring your own legally owned copy of the game (US version,
SLUS-21503). There is no game data in this download, and there never
will be.

## What is new in this build

- Three control styles made for a phone instead of cloned from a PS2
  pad — Brawler Clean, Gesture Evade, Radial Pro — pick yours in the
  settings.
- Player mode and Developer mode. Player mode is the clean game;
  Developer mode shows the boot log and the technical knobs.
- One proper START button in every control style. That is the cutscene
  skip — it sits where your thumb expects it.
- Player mode runs the performance options automatically, and a full
  push forward on the move stick dashes on its own — no double flick
  needed.
- Widescreen on and 1x resolution as the shipped defaults, everything
  set to the values that measured best.

## Honest state

Playable today. Still unstable: busy areas still drop frames, and the
sound is about 80% of the way there and still being improved. It is
marked as a pre-release because that is what it is.

## Install

1. Download the zip and extract the APK (the bare APK is attached too,
   if you prefer it).
2. Install it — it installs over m39/m40/m41 if you already have one of
   those.
3. Open the app, pick your game ISO, play.

## Help wanted

This is a one-person project and it is open now. The most useful thing
you can send is a bug report with a boot log attached: switch to
Developer mode in the settings, play until something breaks, then use
Share boot log in the launcher and attach the file to your issue, along
with your phone model. See CONTRIBUTING.md for where help is needed
most — performance and audio tuning, testing on other phones, control
style feedback, later-stage playtesting.
